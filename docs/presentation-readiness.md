# Подготовка презентационной версии

Этот пакет подготовлен в отдельной ветке от `main` (`52ce6b9`). Он не публикует сайт. До отдельного разрешения изменения не объединяются с `main`, поскольку Timeweb автоматически обновляется из этой ветки.

## Поведение кабинетов

| Кабинет | Стартовый раздел | Основные действия |
| --- | --- | --- |
| Руководитель | Главная | Оперативный обзор, все заявки, парк, ремонты, финансы и эффективность |
| Оба менеджера | Заявки и календарь | Свои заявки редактируются, чужие открываются отдельной карточкой для чтения |
| Механик | ТО и ремонты | Ведение ремонтов; все заказы и общий календарь доступны только для чтения |
| Машинист | Смены | Закрытие смены и замечание о неисправности; просмотр ремонтов назначенной техники |
| Бухгалтер | Импорт расходов | Прежние вкладки загрузки, распределения и истории |

Остальные разрешённые разделы доступны через «Все разделы» / «Ещё». Переключение роли закрывает открытую карточку и открывает стартовый раздел. Это предпросмотр локальных ролей, а не авторизация.

Предупреждение в форме ремонта перечисляет активные назначения выбранной машины и обновляется при смене техники или планового срока. Заявки заказчиков не изменяются автоматически. Назначения после планового окончания также требуют внимания, пока готовность не подтверждена. Завершение работ и допуск машины механиком остаются разными действиями.

Счётчик смены использует максимальное достоверное показание из карточки машины и утверждённых смен этой машины не позднее выбранной даты. Ожидающие проверки, возвращённые, некорректные и более поздние записи не подменяют подтверждённое значение. Неизвестное исходное показание остаётся пустым. При сохранении предел проверяется повторно.

## Значение показателей руководителя

- «Всего техники» — число карточек в текущем наборе данных.
- «Отработали сегодня» — уникальные машины с утверждённой сменой, положительными часами и сегодняшней датой. Это не онлайн-контроль работы.
- Текущие статусы показываются отдельно: свободна, зарезервирована без утверждённой смены сегодня, смена сегодня без блокировки, ремонт / нет допуска. Они используют существующий порядок определения статуса. Отработавшая машина может позднее оказаться на ремонте.
- Сигналы «Требуют внимания» могут относиться к одной машине несколько раз; они не объявлены количеством уникальных проблем.
- Финансовые формулы сохранены. Результат по учтённым расходам и маржа не являются бухгалтерской чистой прибылью. Суммы презентационного набора явно обозначены как условные.

## Сценарий на 10–15 минут

Проводить в одном окне отдельного браузерного профиля с синтетическим набором. Не очищать хранилище рабочего профиля и не пользоваться сбросом данных. До показа проверить свободный интервал, назначение машиниста и отсутствие уже закрытой смены на выбранную дату. Демонстрационные записи сохраняются между открытиями, поэтому исходные даты и номера могут отличаться.

| Время | Действие | Ожидаемый результат |
| --- | --- | --- |
| 0–1 мин | Руководитель: кратко показать главную и оговорить локальный демонстрационный режим | Показатели имеют определения; условные деньги не представлены как сведения компании |
| 1–4 мин | Менеджер №1: открыть календарь, подобрать экскаватор в свободный интервал, заполнить заказчика, объект, контакт, машиниста и сроки | Заявка сохраняется и появляется в списке и календаре |
| 4–5 мин | Переключиться на менеджера №2, открыть созданную заявку из календаря | Видны сведения и история, отсутствуют элементы изменения |
| 5–8 мин | Механик: открыть общий календарь и ту же заявку; затем создать ремонт другой машины с плановым сроком | Заказ доступен для чтения; назначения выбранной машины показаны предупреждением, если пересекаются с ремонтом или готовность требует уточнения |
| 8–10 мин | Вести ремонт: назначить механика, принять в работу, завершить с описанием результата; затем отдельно подтвердить исправность | Завершение само по себе не снимает блокировку. Допуск не освобождает машину при наличии другого блокирующего ремонта |
| 10–11 мин | Машинист: открыть закрытие смены, проверить исходный счётчик; при необходимости показать замечание на синтетической незакрытой дате | Показание не устаревшее, замечание создаёт связанную запись ремонта; смену проверяет механик или руководитель |
| 11–12 мин | Бухгалтер: показать вкладки, загрузить заранее подготовленный синтетический CSV/XLSX в предпросмотр | Видны новые, обработанные и требующие сверки строки. Подтверждать импорт только в демонстрационном наборе |
| 12–15 мин | Руководитель: вернуться на главную, открыть заявки, парк и финансовый раздел | Стартовая страница корректна; изменения в том же браузере доступны другим локальным ролям |

В первоначальном демонстрационном наборе у экскаватора `M002` уже есть заказ на ближайшие дни: перед показом нужно выбрать свободный интервал после него. У `M001` может быть утверждённая смена за сегодня; повторно закрывать её нельзя. Нулевые затраты при показе завершения ремонта позволяют не добавлять лишних условных финансовых операций.

## Воспроизводимые проверки

```sh
node --check dist/app.js
node --check dist/workshop.js
node --check dist/accountant.js
node --test tests/*.test.cjs
python tests/browser/manager-calendar.py
python tests/browser/presentation-readiness.py
```

Для браузерных проверок нужны Python Playwright и Chromium; путь можно задать через `MARS_CHROMIUM_PATH`. Страницы загружаются из локального `dist` через перехват запросов. Все записи создаются в изолированных контекстах; действующий Timeweb и хранилище пользователя не используются. XLSX-проверка требует доступного локального файла библиотеки XLSX, путь и итог выполнения указывает браузерный сценарий.

Для проверки настоящего XLSX-файла можно задать `MARS_XLSX_PATH` — путь к локальной библиотеке SheetJS 0.18.5. Без неё этот дополнительный шаг явно отмечается как пропущенный. Телефонные размеры проверяются в Chromium; экранная клавиатура и особенности Safari/iOS этими тестами не проверяются.

Результат проверки пакета:

- 12 из 12 прежних браузерных сценариев календаря.
- 48 из 48 новых изолированных сценариев Chromium: оба набора данных, шесть вариантов кабинета, ширина 320/390/1280 px, формы, права, предупреждения, отказы сохранения, повторная отправка и перезагрузка.
- CSV прошёл подтверждение, повторный импорт и восстановление. Настоящий XLSX-файл прошёл предпросмотр в обоих режимах через локальную SheetJS 0.18.5; проведение XLSX отдельно не выполнялось.

## Оставшиеся ограничения

Общей базы, серверной авторизации и обмена между устройствами нет. Несколько вкладок одного профиля могут перезаписать состояние целиком; для показа использовать одну вкладку. Отдельный профиль или устройство имеет собственные данные. Резервные выгрузки JSON и ограничения объёма localStorage сохраняются.

Календарь не восстанавливает неизвестные исторические даты ремонта. Плановая дата не гарантирует техническую готовность. Предупреждение о пересечении не согласует перенос с менеджером и не отправляет уведомлений. Показатели работы основаны на введённых сменах, финансовые данные демонстрационные, Excel поддерживает согласованный шаблон, прямого подключения к 1С нет. Для Excel требуется библиотека XLSX, а для проверки файлов по SHA-256 — защищённый контекст HTTPS.

При ревью отмечено прежнее ограничение вне изменённых форм: сохранённый через скрипт обработчик `stockModal` позволяет провести поступление после прямой смены переменной роли. Обычный переключатель роли закрывает форму. Складские алгоритмы в этом пакете не изменялись; локальные проверки интерфейса не следует считать защитой от доступа через консоль или изменения localStorage.

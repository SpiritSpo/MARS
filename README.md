# МАРС

**МонАрх — Анализ Работы Спецтехники**  
ООО «МонАрх и М»

Демонстрационная система управления техникой: парк, объекты, финансы, смены, путевые листы, табели, обслуживание и склад.

## Render

- Тип: Static Site
- Ветка: main
- Build command: `node --check dist/app.js`
- Publish directory: `dist`
- `SKIP_INSTALL_DEPS=true`

## Подготовка к загрузке исходных данных

В версии 2.3 новые наборы не содержат демонстрационных машин, видов техники и объектов. Финансовые и оперативные показатели автоматически не создаются. Справочники заполним после проверки исходных таблиц. Разделы «Техника» и «Объекты» показывают понятные пустые состояния.

При открытии данных версии 2.2 удаляются только нетронутые образцы с `demo:true`, не связанные с введёнными записями. Изменённые карточки и карточки, на которые ссылаются операции, смены, ремонты, заявки, фотографии или назначения сотрудников, сохраняются вместе со связанными объектами. До очистки исходный JSON сохраняется в `mars-catalog-archive-v1`; первая копия не перезаписывается. Скачать её можно в настройках. Если архив или очищенный набор сохранить не удалось, исходный набор остаётся без изменений.

Рабочий набор по-прежнему хранится в `mars-working-data-v1`. Прежний ключ `monarch-im-control-v1` не изменяется и не удаляется: его исходный JSON доступен через «Скачать прежние данные». Автоматического восстановления архивов нет: сначала нужна сверка содержимого. При повреждённом текущем файле запись блокируется, а исходный файл можно скачать.

Периоды строятся по датам записей и текущему месяцу. Изменения сохраняются только в этом браузере; общей базы и интеграции с 1С нет. Переключение ролей является предпросмотром интерфейса, а не авторизацией сотрудников. Путевые листы остаются черновиками. Налоги, амортизация и распределение общих расходов по машинам не реализованы.

## Excel / CSV

Импорт расходов поддерживает шаблон `Дата;Техника;Статья;Сумма;Комментарий`; скачиваемый CSV содержит только заголовки. Идентификаторы техники, назначение расходов, исходные документы и формат реальной выгрузки необходимо согласовать по предоставленным таблицам. Загрузка произвольной структуры Excel и импорт справочника техники пока не реализованы.

Складской приход и стоимость списания не связаны с бухгалтерской закупкой; до отдельной доработки это не полноценный стоимостной учёт склада. Существующие проверки возможных дублей не заменяют сверку первичных документов.

## Проверки

```sh
node --check dist/app.js
node --check dist/workshop.js
node --check dist/accountant.js
node --test tests/*.test.cjs
```

В ограниченном исполнителе можно выполнить `node --test --test-isolation=none --test-reporter=tap tests/*.test.cjs`, чтобы получить результаты каждого теста. Демонстрационные суммы сохранены только в тестовых фикстурах и не подключаются приложением; описания прежних образцов в коде используются только для безопасного распознавания неизменённых карточек при очистке.

Timeweb App Platform может публиковать ту же ветку `main`: HTML/CSS/JS, директория `/dist`. Перед слиянием необходимо проверить фактическое автоматическое развёртывание. Подготовка этой версии сама по себе не публикует сайт.

# МАРС

**МонАрх — Анализ Работы Спецтехники**  
ООО «МонАрх и М»

Демонстрационная система управления техникой: парк, объекты, финансы, смены, путевые листы, табели, обслуживание и склад.

## Render

- Тип: Static Site
- Ветка: main
- Build command: `node --check dist/app.js`
- Publish directory: `dist`
- `SKIP_INSTALL_DEPS=true`

## Подготовка к загрузке исходных данных

В версии 2.2 оставлены образцы справочников техники и объектов. Они помечены как неподтверждённые карточки. Встроенные выручка, расходы, часы, тарифы, стоимость техники, показания счётчиков, ремонты, смены и складские остатки больше не создаются. Отсутствующие показатели отображаются как «Нет данных» или «Не указано»; подтверждённый нулевой результат остаётся нулём.

Новый набор хранится отдельно в `mars-working-data-v1`. Прежний ключ `monarch-im-control-v1` не изменяется и не удаляется: исходный JSON доступен через «Скачать прежние данные» в уведомлении и настройках. Архив включает ранее введённые записи и не участвует в новых расчётах. Автоматического переноса или восстановления архива в новый набор нет: сначала нужна сверка содержимого. При повреждённом текущем файле запись блокируется, а исходный файл можно скачать.

Периоды строятся по датам записей и текущему месяцу. Изменения сохраняются только в этом браузере; общей базы и интеграции с 1С нет. Переключение ролей является предпросмотром интерфейса, а не авторизацией сотрудников. Путевые листы остаются черновиками. Налоги, амортизация и распределение общих расходов по машинам не реализованы.

## Excel / CSV

Импорт расходов поддерживает шаблон `Дата;Техника;Статья;Сумма;Комментарий`; скачиваемый CSV содержит только заголовки. Идентификаторы техники, назначение расходов, исходные документы и формат реальной выгрузки необходимо согласовать по предоставленным таблицам. Образцы машин не подтверждают состав парка компании. Загрузка произвольной структуры Excel и импорт справочника техники пока не реализованы.

Складской приход и стоимость списания не связаны с бухгалтерской закупкой; до отдельной доработки это не полноценный стоимостной учёт склада. Существующие проверки возможных дублей не заменяют сверку первичных документов.

## Проверки

```sh
node --check dist/app.js
node --check dist/workshop.js
node --check dist/accountant.js
node --test tests/*.test.cjs
```

В ограниченном исполнителе можно выполнить `node --test --test-isolation=none --test-reporter=tap tests/*.test.cjs`, чтобы получить результаты каждого теста. Демонстрационные суммы сохранены только в тестовой фикстуре `tests/fixtures/demo-state.cjs` и не подключаются приложением.

Timeweb App Platform может публиковать ту же ветку `main`: HTML/CSS/JS, директория `/dist`. Перед слиянием необходимо проверить фактическое автоматическое развёртывание. Подготовка этой версии сама по себе не публикует сайт.

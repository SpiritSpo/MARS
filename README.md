# МАРС

**МонАрх — Анализ Работы Спецтехники**  
ООО «МонАрх и М»

Демонстрационная система управления техникой: парк, объекты, финансы, смены, путевые листы, табели, обслуживание и склад.

## Render

- Тип: Static Site
- Ветка: main
- Build command: `node --check dist/app.js`
- Publish directory: `dist`
- `SKIP_INSTALL_DEPS=true`

## Ограничения демонстрации

Исходные данные условные. Записи хранятся в браузере (localStorage), общей базы и интеграции с 1С пока нет. Роли демонстрационные, серверной авторизации нет. Путевые листы — демонстрационные черновики.

## Версия 1.1: паспорт и ремонт

- Паспорт техники: условные номера, характеристики, демофото, история, образцы документов и экономика для руководителя.
- Заявки: ответственный, приоритет, срок, остановка техники, фотографии и история изменений.
- Замечание при закрытии смены создаёт связанную заявку сразу, независимо от утверждения часов диспетчером. Повторная отправка исправленной смены не дублирует заявку.
- Механик принимает заявку в работу, отмечает ожидание запчастей и завершает ремонт с описанием результата.
- Завершение атомарно списывает запчасти и добавляет одну расходную операцию, если стоимость больше нуля. Второй открытый ремонт сохраняет остановку машины. При ошибке сохранения изменения откатываются.
- Фото уменьшаются в браузере, максимум 3 на заявку, JPG/PNG/WebP. На сервер не отправляются. Исходные образцы — схемы, а не фотографии реальной техники.
- Старые локальные записи сохраняются при обновлении. Новые поля добавляются без сброса данных.

Для показа: «Техника» → паспорт JCB 531-70 → «История» → заявка, либо «ТО и ремонты» → заявка → «Завершить ремонт».

Проверки: `node --check dist/app.js`, `node --check dist/workshop.js`, `node --test tests/workshop.test.cjs`.

Timeweb App Platform может публиковать ту же ветку `main`: HTML/CSS/JS, директория `/dist`. URL уже созданного приложения сохраняется при его обновлении.

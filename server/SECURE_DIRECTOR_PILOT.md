# MARS: защищённый показ финансов директору

## Решение
Текущий Timeweb HTML/CSS/JS сайт не является защищённым хранилищем. **Не загружать** исходные Excel, реестры и финансовые JSON в публичную папку `dist`, JavaScript или localStorage. Секретная ссылка или клиентская форма пароля не обеспечивают защиту.

## План безопасного внедрения
1. Оставить действующий сайт и ветку `main` без изменений. Разрабатывать в `feature/server-finance-foundation`.
2. Развернуть отдельный сервер MARS API на Timeweb Cloud (Node.js) с HTTPS и закрытой PostgreSQL; не создавать платные ресурсы без подтверждения владельца.
3. Хранить пользователей на сервере. Пароли — только стойкие хеши (Argon2id или scrypt), с ограничением попыток входа; защищённые сессии в HttpOnly, Secure, SameSite cookies. Не хранить пароли в GitHub.
4. Все API финансов, отчётов, загрузки Excel и экспорта должны проверять сессию и роль на сервере. Роль `director` видит финансы, прочие роли — нет. Для пилота допускается учётная запись только директора и владельца.
5. До загрузки бухгалтерских данных: проверить вход/выход, отказ в доступе без входа, запрет доступа чужой роли, запрет прямого скачивания файла и выгрузки через API, отсутствие финансов в публичном HTML/JS, защиту от повторной загрузки.
6. Источник импорта — 9 месячных Excel. Два файла `(ФОРМАТ)` использовать только для сверки; не включать в финансовые суммы повторно.
7. Сохранять исходные значения и журнал загрузки. Для расхождений показывать ⚠ с периодом, машиной, проверяемой формулой и разницей; не исправлять исходные значения автоматически.
8. Протестировать на копии/стенде, затем отдельно согласовать подключение действующего сайта и создание платных ресурсов.

## Критерии готовности к показу
- Без логина невозможно открыть финансовый API, скачать исходный Excel или прочитать финансовые данные через исходный код страницы.
- Директор видит суммы по машинам/месяцам, предупреждения и источники данных.
- Повторная загрузка тех же файлов не удваивает суммы.
- Суммы по 9 месячным отчётам сверены с исходниками, расхождения сохранены.
- Резервная копия и восстановление проверены.

**Статус:** план, не развёрнутая защита. До прохождения проверок не публиковать реальные финансы.
